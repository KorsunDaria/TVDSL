
# HW3: типы и семантические проверки

Запуск:

```
python3 funny_checker.py prog.funny   
python3 test_checker.py             
```

**Что проверяется:**

- имена: повторные объявления, необъявленные переменные, неизвестные функции (функции видны только после определения, рекурсия разрешена);
- выражения и операторы: арифметика и сравнения на `int`, условия и предикаты на `bool`, индексы массивов;
- вызовы: число и типы аргументов, число значений в `x, y = f(...)`;
- области видимости: параметры, `returns`, `uses`; `requires` видит параметры, `ensures` — ещё и результаты; квантор — своя область.

**+** если переменная не объявлена в `uses`, её тип выводится по первому присваиванию и добавляется в `locals`; присваивание другого типа — ошибка.

**Ошибки:** `файл:строка:столбец: ошибка: сообщение`, выводятся все сразу.
