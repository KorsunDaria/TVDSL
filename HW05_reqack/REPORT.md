# Отчёт по HW5. Темпоральные спецификации и проверка моделей

## 2. Свойства

| № | Тип        | Смысл                                                              | Формула                                                      | Результат |
| -- | ------------- | ----------------------------------------------------------------------- | ------------------------------------------------------------------- | ------------------ |
| S1 | Safety, LTL   | ACK при `timer = 1`                                                | `G (chan_ack -> timer = 1)`                                       | Истина       |
| S2 | Safety, LTL   | ACK пока клиент ждёт                                      | `G (chan_ack -> client = waiting)`                                | Истина       |
| S3 | Safety, LTL   | Тайм-аут  при `timer = 3`                                  | `G (client = done_to -> timer = 3)`                               | Истина       |
| L1 | Liveness, LTL | Ожидание всегда чем-то заканчивается    | `G (client = waiting -> F (client = done_ok \| client = done_to))` | Истина       |
| L2 | Liveness, LTL | Ожидание всегда заканчивается успехом | `G (client = waiting -> F client = done_ok)`                      | Ложь           |
| P6 | CTL           | Существует путь к успеху при `timer = 3`      | `EF (client = done_ok & timer = 3)`                               | Ложь           |

Вспомогательные

- `C1 = AG (client = waiting -> AF (client = done_ok | client = done_to))` — CTL-версия L1, истинна.
- `C2 = EF client = done_ok` — успех в принципе достижим, истинна.

## 3. Результаты

Пять LTL-свойств проверены в NuSMV и Spin, вердикты совпали. CTL (P6, C1, C2) проверен в NuSMV.

| Свойство | NuSMV 2.7.1 (BDD)                | Spin 6.5.2 (POR)                          |
| ---------------- | -------------------------------- | ----------------------------------------- |
| S1               | Истина                     | Истина, `errors: 0`               |
| S2               | Истина                     | Истина, `errors: 0`               |
| S3               | Истина                     | Истина, `errors: 0`               |
| L1               | Истина                     | Истина, `errors: 0`               |
| L2               | Ложь, контрпример | Ложь, acceptance cycle, `errors: 1` |

CTL в NuSMV: P6 — ложь, C1 — истина, C2 — истина.
