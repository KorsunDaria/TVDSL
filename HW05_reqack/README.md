# HW5. Темпоральные спецификации и проверка моделей

## Состав

| Файл                | Назначение                                                                       |
| ----------------------- | ------------------------------------------------------------------------------------------ |
| `model/reqack.smv`    | модель NuSMV: 5 LTL (S1–S3, L1, L2), CTL P6 + вспомогательные C1, C2 |
| `model/reqack.pml`    | модель Promela, 5 LTL-свойств                                                 |
| `tools/verify.py`     | явный перебор состояний, свидетельства для CTL        |
| `tools/run_checks.py` | автозапуск всех проверок, замер времени и памяти  |
| `logs/`               | логи запусков и `summary.md`                                                |
| `REPORT.md`           | отчёт                                                                                 |

## Запуск

```bash
python3 tools/run_checks.py
```

Скрипт запускает NuSMV (BDD), Spin (POR, без POR, bitstate) и Python-проверку, пишет логи в `logs/` и сводку в `logs/summary.md`.
