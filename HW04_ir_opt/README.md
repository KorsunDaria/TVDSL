
# HW4: IR, CFG, оптимизации, раскраска

## Запуск

```
python3 funny_ir.py program.funny [--opt ...] [--dot] [--out DIR]
```

- `--opt const,alg,cse,dce` — включить выбранные оптимизации (также `all` и `none`, по умолчанию `const,alg,dce`).
- `--dot` — дополнительно записать CFG и граф конфликтов в DOT.
- `--out DIR` — каталог вывода (по умолчанию рядом с исходником).

Выход: `<файл>.ir.txt` и `<файл>.ir.json` (IR до/после, раскраска, метрики).

## Формат IR

Операнд — имя (переменная или временная `%tN`) либо целая константа.

| инструкция                       | смысл                                              |
| ------------------------------------------ | ------------------------------------------------------- |
| `L:`                                     | метка (первая — `entry`)                  |
| `d = mov a`                              | копия / константа                         |
| `d = add\|sub\|mul\|div a b`, `d = neg a` | арифметика                                    |
| `d = alen arr`, `d = aload arr i`      | `length(arr)`, `arr[i]`                             |
| `d = aupd arr i v`                       | копия массива с `[i]=v`                  |
| `d1, d2 = call f a b`                    | вызов                                              |
| `br <cmp> a b Lt Lf`                     | условный переход                         |
| `jmp L`, `ret r1, r2`, `trap`        | переход, возврат, провал `assert` |

## Оптимизации

- `const` — константы, копии, свёртка, `br` с константами → `jmp`.
- `alg` — `x+0`, `x*1`, `x*0`, `x-x`, `x/1`, `x*2`.
- `cse` — общие подвыражения в блоке.
- `dce` — мёртвые присваивания.
