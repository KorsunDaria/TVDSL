# HW1 — Лексер Funny: regex → НКА → ДКА → минимизация

## Состав

- `lexer.py` — построение НКА (конструкции Томпсона), потом ДКА,
  минимизация ДКА, экспорт таблицы переходов, функция `tokenize()`.
- `test_lexer.py` — тесты на граничные случаи.
- `REPORT.md` — отчёт: список regex, размер ДКА до/после минимизации, описание ловушки.
- `dfa_table.json` — таблица переходов минимизированного ДКА

## Запуск

```bash
python3 lexer.py            # строит автомат, печатает отчёт и таблицу переходов
                

python3 test_lexer.py       # прогон тестов
```
