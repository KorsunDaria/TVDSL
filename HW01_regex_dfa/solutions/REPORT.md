# Отчёт — HW1. Лексер Funny

## 1. Список регулярных выражений для токенов

| Токен(ы)                                                                                                                       | Регулярное выражение                                                                                                                      | skip   |
| ------------------------------------------------------------------------------------------------------------------------------------ | ------------------------------------------------------------------------------------------------------------------------------------------------------------ | ------ |
| `KW_FUNCTION`, `KW_RETURNS`, `KW_WHILE`, `KW_IF`, `KW_ELSE`, `KW_ASSERT`, `KW_ASSUME`, `KW_INVARIANT`, `KW_LENGTH` | по одному литералу на слово:`function`, `returns`, `while`, `if`, `else`, `assert`, `assume`, `invariant`, `length` | нет |
| `IDENT`                                                                                                                            | `[a-zA-Z][a-zA-Z0-9]*`                                                                                                                                     | нет |
| `INT`                                                                                                                              | `0 \| [1-9][0-9]*`                                                                                                                                          | нет |
| `WS`                                                                                                                               | `[ \t\r\n]+`                                                                                                                                               | да   |
| `COMMENT`                                                                                                                          | `//[^\r\n]*` (любой печатный ASCII-символ кроме CR/LF, до конца строки/файла)                                    | да   |
| `LPAREN` … `SLASH` (19 шт.)                                                                                                   | по одному литералу на символ/пару символов:`( ) [ ] { } , ; + - * / == != <= >= < > =`                                 | нет |

Приоритет при конфликте - ключевые слова добавлены
в НКА раньше `IDENT`, поэтому при полном совпадении (`"function"` подходит и под
ключевое слово, и под `IDENT`) выигрывает ключевое слово. Операторы разной длины
(`==` vs `=`) конфликтов не создают — длинный вариант побеждает автоматически за счёт
maximal munch, приоритет тут не нужен.

## 3. Ловушка

Явного состояния-ловушки в таблице нет: отсутствие перехода по символу из
текущего состояния (пустая ячейка в `dfa_table.csv`) уже и есть ловушка.
При сканировании (`tokenize`) это обрабатывается так: если от текущей позиции
не удалось дойти ни до одного принимающего состояния, символ считается ошибочным
— эмитится токен `ERROR` длиной 1 символ, и сканирование продолжается со
следующей позиции. Символы вне ASCII (например, `é`) не входят ни в один
алфавит правил и всегда попадают в ловушку.

## 4. Тесты (входные строки → ожидаемый результат)

Полный список — в `test_lexer.py`, здесь сводка обязательных сценариев из задания:

| Вход                           | Ожидаемые токены                                                                                   |
| ---------------------------------- | ----------------------------------------------------------------------------------------------------------------- |
| `''` (пустая строка) | `[]`                                                                                                            |
| `'   \t\r\n  '`                  | `[]`                                                                                                            |
| `'0'`                            | `['INT']`                                                                                                       |
| `'00'`                           | `['INT', 'INT']` (ведущий ноль не даёт одному INT поглотить второй `0`) |
| `'01'`                           | `['INT', 'INT']`                                                                                                |
| `'foo_bar'`                      | `['IDENT', 'ERROR', 'IDENT']` (`_` не входит в алфавит `IDENT`)                             |
| все 9 ключевых слов | по одному`KW_*` токену каждое                                                               |
| `'()[]{},;'`                     | `LPAREN, RPAREN, LBRACKET, RBRACKET, LBRACE, RBRACE, COMMA, SEMI`                                               |
| `'+ - * / == != <= >= < > ='`    | `PLUS, MINUS, STAR, SLASH, EQ, NEQ, LE, GE, LT, GT, ASSIGN`                                                     |
| `'// comment to eol'`            | `[]`                                                                                                            |
| `'é'`                           | `['IDENT', 'ERROR']` (`é` вне ASCII → ловушка)                                                    |

## 5. Воспроизводимость

`python lexer.py` детерминированно пересобирает НКА → ДКА → минимизированный ДКА
и перезаписывает `dfa_table.csv` при каждом запуске.
